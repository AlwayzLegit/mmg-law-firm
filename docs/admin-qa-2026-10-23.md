## Suggested follow-ups (code)

1. **Content agent dedupe.** Before claiming a topic, reject titles/slugs
   that match an existing post after stripping a trailing `-N`, and never
   generate a `-N` slug for a published title. Highest value: it stops the
   duplicate stream at the source.
2. **Channel column on the leads list.** Attribution is captured and shown
   per lead; a compact Channel column (or a filter chip) on `/admin/leads`
   would answer "where do leads come from" without opening each one.
3. **Scoped API key for the content agent.** Every agent action in the audit
   log is attributed to the legacy shared `ADMIN_API_KEY`. Create a key with
   the "Blog agent preset" on `/admin/settings/api-keys`, switch the agent to
   it, then clear `ADMIN_API_KEY` on Vercel.
4. **Media library search and captions.** 150 images with no names or alt
   text in the grid.
5. **Case card editable.** Practice area / county / city are blank on leads
   that skipped the optional form fields and intake can't set them from the
   lead page.
6. **City × practice uniqueness spot check.** All 650 pages are published;
   RLS enforces a non-empty local angle, not a unique one. Sample a few for
   templated copy.
